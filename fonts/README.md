# فونت (`fonts`)

فونت **Kalameh** در هفت وزن (light تا black)، تنها فونت سایت و پنل.

| فایل | کار |
|---|---|
| `kalameh-*.woff2` | فایل‌های فونت. **مجوز خصوصی دارند** و چون مخزن عمومی است، در گیت نیستند (`.gitignore`). |
| `FontLicense.txt` | متن مجوز. |

- روی کامپیوتر خودتان: فایل‌ها را در `web/public/fonts/` کپی کنید.
- روی هاست: یک بار با دست در `public_html/fonts/` بارگذاری کنید (استقرار خودکار آن‌ها را نمی‌فرستد).
- بسته آفلاین آن‌ها را دارد؛ بسته را عمومی منتشر نکنید.
