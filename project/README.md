# فایل‌های طراحی (`project`)

خروجی بوم طراحی Claude Design: صفحه‌های طراحی‌شده به شکل فایل `.dc.html`. **صفحه واقعی سایت نیستند** و به تنهایی اجرا نمی‌شوند (به `support.js` بوم نیاز دارند). مرجع دقیق ساختار، متن، حالت‌ها و فاصله‌ها هستند. داده هر صفحه در اسکریپت `renderVals()` پایین فایل است.

> ظاهر نهایی سایت و پنل به درخواست کارفرما از این طرح‌ها به سبک ClickUp تغییر کرد (`../DESIGN.md`). محتوا، رفتار، متن‌ها و قانون‌های این طرح‌ها هنوز مرجع‌اند.

## فایل‌ها

| فایل | چیست |
|---|---|
| `canvas.json` | فهرست همه صفحه‌های طراحی با عنوان و گروه. |
| `Main.dc.html` | جریان کلیک‌پذیر موبایل: خانه ← فیلتر ← محصول ← استعلام ← واتساپ. رفتار مورد انتظار را نشان می‌دهد. |
| `M-*.dc.html` | صفحه‌های موبایل ۳۹۰ پیکسل: خانه، لیست، فیلتر، محصول، استعلام، جست‌وجو، مقایسه، راهنما، درباره، حالت‌ها. |
| `D-*.dc.html` | صفحه‌های دسکتاپ ۱۴۴۰ پیکسل: خانه، لیست، محصول، مقایسه، لایه‌های روی صفحه. |
| `T-List.dc.html` | لیست تبلت ۸۳۴ پیکسل. |
| `A-*.dc.html` | پنل مدیریت: ورود، نمای کلی، محصولات، ویرایش محصول، دسته‌ها، برندها، رسانه، استعلام‌ها، کاربران، فعالیت، تنظیمات، به‌روزرسانی، موبایل، تبلت، اجزا. `A-FlowEdit` و `A-FlowUpdate` دو جریان کلیک‌پذیرند. |
| `DesignSystem.dc.html`، `Components.dc.html` | پایه‌ها (رنگ، فونت، فاصله) و همه حالت‌های اجزا. |
| `Icon.dc.html` | مجموعه آیکون‌ها (منبع `web/app/Support/Icons.php`). |
| `ProductArt.dc.html` | نقاشی‌های جای عکس محصول (منبع `web/resources/views/partials/art-sprite.blade.php`). |
| `fz.css`، `adm.css` | توکن‌ها و اجزای طراحی؛ به `web/public/css` پورت شده‌اند. |
| `fritz-logo.png`، `fritz-logo-dark.png`، `fritz-logo-original.png` | لوگوی کارفرما؛ نسخه تیره فقط خط خاکستری «SMART SOLUTIONS» را روشن کرده. |

## ساخته شده از این طرح‌ها
- همه صفحه‌های `M-*`، `D-*` و `Main` (با ظاهر ClickUp).
- از پنل: `A-Login`، `A-Overview`، `A-Products`، `A-ProductEdit`، `A-FlowEdit`، `A-Settings`، `A-Update`، `A-FlowUpdate`، `A-Mobile`.

## هنوز ساخته نشده
- `A-Inquiries`، `A-Categories`، `A-Brands`، `A-Media`، `A-Users`، `A-Activity`، `A-Tablet`، و تنظیم دقیق `T-List`.
- لوگوی SVG از کارفرما.
