# آزمون‌های خودکار (`tests`)

۵۱ اجرای آزمون با ۳۷۵ بررسی، همه سبز (۴۱ تابع آزمون؛ آزمون «صفحه‌های عمومی باز می‌شوند» برای چند آدرس تکرار می‌شود). اجرا: `cd web && php artisan test`. هر آزمون یک پایگاه داده تازه SQLite در حافظه می‌سازد و به داده واقعی دست نمی‌زند.

| فایل | تعداد | چه چیزی را می‌سنجد |
|---|---|---|
| `Feature/CatalogTest.php` | ۷ | همه صفحه‌های عمومی باز می‌شوند؛ **هیچ‌جا قیمت یا موجودی نیست**؛ پروتکل غیرفعال و محصول پیش‌نویس عمومی نمی‌شوند؛ فیلتر دسته؛ جست‌وجوی کد بدون خط تیره؛ پوسته جدید (درخت، نوار پایین، Ctrl+K). |
| `Feature/InquiryLogTest.php` | ۳ | ثبت کلیک استعلام با نام و کد آن لحظه؛ رد محصول ناشناخته یا پیش‌نویس؛ محدود کردن تعداد و طول متن. |
| `Feature/DeployHookTest.php` | ۳ | `/_deploy` بدون کلید پنهان است، کلید اشتباه رد می‌شود، فرم مرورگر کار می‌کند. |
| `Feature/AdminTest.php` | ۹ | ورود و خروج، قفل پس از تلاش‌های اشتباه، حساب غیرفعال، محدودیت نقش ویرایشگر، تنظیمات، راه‌اندازی اولین مدیر، فارسی بودن صفحه‌ها. |
| `Feature/AdminProductTest.php` | ۱۰ | لیست و فیلتر، ساخت و انتشار با عکس و دیتاشیت، مانع انتشار، کد تکراری، قیمت داخلی فقط برای مدیر کل، حذف و بازگردانی، کپی، سه نما، پنل کناری و تغییر وضعیت در جا. |
| `Feature/AdminUpdateTest.php` | ۷ | اکسل: پیش‌نمایش، اعمال، بازگردانی؛ حذف غایب‌ها فقط با تأیید؛ `.fritz` با رمز اشتباه، دستکاری‌شده و فایل غیربسته؛ تغییر رمز بسته؛ فایل خراب؛ خروجی و ابزار ساخت؛ بسته بودن برای ویرایشگر. |
| `Unit/FaTest.php` | ۲ | رقم فارسی و یکسان‌سازی متن و کد. |
| `TestCase.php` | — | پایه همه آزمون‌ها. |

## باقی‌مانده
- آزمون برای هر بخش جدید پنل هم‌زمان با ساختنش.
- اجرای خودکار پیش از هر استقرار در GitHub Actions آماده است؛ با راه‌اندازی آن فعال می‌شود.
