# نگهبان‌های درخواست (`app/Http/Middleware`)

پیش از رسیدن درخواست به کنترلرهای پنل اجرا می‌شوند. در `bootstrap/app.php` با نام کوتاه ثبت شده‌اند.

| فایل | نام کوتاه | کار |
|---|---|---|
| `EnsureActiveUser.php` | `active` | کاربری را که مدیر غیرفعالش کرده، حتی وسط کار، از پنل بیرون می‌کند. |
| `EnsureRole.php` | `role:admin` | بخش‌های «فقط مدیر کل» (تنظیمات، به‌روزرسانی، کاربران) را برای «ویرایشگر محتوا» با خطای ۴۰۳ می‌بندد. |

## انجام‌شده
- هر دو نگهبان با آزمون (`AdminTest`).

## باقی‌مانده
- تأیید دومرحله‌ای ورود برای مدیر کل (پیشنهادی، پس از راه‌اندازی).
