# کنترلرهای پنل مدیریت (`app/Http/Controllers/Admin`)

همه آدرس‌های زیر `/admin`. ورود لازم است؛ بخش‌های قفل‌دار فقط برای «مدیر کل» هستند (`role:admin`). هر کار خطرناک در صفحه با پنجره تأیید همراه است و در `activity_log` ثبت می‌شود.

## فایل‌ها

| فایل | آدرس | کار |
|---|---|---|
| `AuthController.php` | `/admin/login`، `logout` | ورود با ایمیل و رمز؛ پس از ۵ تلاش اشتباه ۱۵ دقیقه قفل؛ حساب غیرفعال وارد نمی‌شود. |
| `SetupController.php` | `/admin/setup` | ساخت اولین «مدیر کل» با کلید `DEPLOY_TOKEN`، بدون SSH. پس از ساخت اولین مدیر بسته می‌شود. |
| `OverviewController.php` | `/admin` | نمای کلی با آمار واقعی: تعداد محصولات، استعلام هفته، پراستعلام‌ترین، نمودار ۱۲ هفته، سهم برند و پروتکل، «نیاز به توجه»، فعالیت اخیر. |
| `ProductController.php` | `/admin/products/...` | لیست با سه نما (لیست گروه‌بندی‌شده، جدول، بُرد)، فیلتر، «فقط ناقص‌ها»، عملیات گروهی، فرم کامل (فیلدهای پویای هر دسته، عکس WebP، دیتاشیت، «سازگار با»، قیمت داخلی)، کپی، حذف با بازگردانی ۳۰ روزه، پنل کناری (`peek`) و تغییر وضعیت در جا (`status`). |
| `UpdateController.php` | `/admin/update/...`، `settings/key` | به‌روزرسانی گروهی از اکسل یا `.fritz`: بارگذاری، اعتبارسنجی، پیش‌نمایش تغییرها، گزینه‌ها، اعمال با پشتیبان، بازگردانی، تاریخچه، خروجی اکسل و قالب خالی، ابزار ساخت بسته، تعیین رمز بسته. فقط مدیر کل. |
| `SettingsController.php` | `/admin/settings` | شماره و قالب پیام واتساپ، اطلاعات تماس، سئو و اجازه ایندکس. فقط مدیر کل. |
| `SoonController.php` | `/admin/{بخش}` | صفحه صادقانه «مرحله بعد» برای بخش‌هایی که هنوز ساخته نشده‌اند (به‌جای لینک خراب). |

## انجام‌شده
- ورود، نقش‌ها، راه‌اندازی بدون SSH.
- نمای کلی، تنظیمات، محصولات کامل، به‌روزرسانی کامل.
- پوسته ClickUp: درخت کاتالوگ، Ctrl+K، «+ جدید».

## باقی‌مانده (در `SoonController` فهرست شده‌اند)
- **استعلام‌ها**: لیست کلیک‌های ثبت‌شده، وضعیت (جدید / پیگیری / بسته)، یادداشت، خروجی اکسل. جدول‌های `inquiries` و `inquiry_items` آماده‌اند.
- **دسته‌ها و فیلترها**: افزودن و ویرایش دسته و فیلدهای هر دسته (فعلاً فقط از `CatalogSeeder`).
- **برندها و پروتکل‌ها**: ویرایش، لوگوی برند، فعال/غیرفعال.
- **رسانه**: کتابخانه عکس و فایل، جایگزینی، پیدا کردن فایل‌های بی‌استفاده.
- **کاربران**: دعوت با لینک (جدول `user_invites` آماده است)، غیرفعال کردن، تغییر نقش.
- **گزارش فعالیت**: صفحه کامل `activity_log` با فیلتر.
- بازیابی رمز فراموش‌شده (نیاز به تنظیم ایمیل روی هاست).
