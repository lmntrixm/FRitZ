# کنترلرهای عمومی (`app/Http/Controllers`)

هر کنترلر به یک یا چند آدرس عمومی کاتالوگ پاسخ می‌دهد: داده را از پایگاه داده می‌خواند و صفحه Blade را می‌سازد. **هیچ‌کدام قیمت، موجودی یا سبد خرید برنمی‌گرداند.** کنترلرهای پنل در [`Admin/`](Admin/README.md) هستند.

## فایل‌ها

| فایل | آدرس | کار |
|---|---|---|
| `Controller.php` | — | کلاس پایه خالی Laravel. |
| `CatalogController.php` | `/`، `/c/{دسته}`، `/about` | خانه (منتخب‌ها، دسته‌ها با تعداد، برندها، عدد «بیش از ۴۰۰» فقط وقتی واقعاً هست)؛ صفحه دسته با فیلترهای مخصوص آن دسته؛ درباره و تماس. |
| `ProductController.php` | `/p/{محصول}` | صفحه محصول: مشخصات فنی، «سازگار با»، «مرتبط»، دیتاشیت. پیش‌نویس فقط برای کاربر واردشده به پنل دیده می‌شود. |
| `SearchController.php` | `/search`، `/search/suggest` | جست‌وجو با نام فارسی یا کد مدل (بدون حساسیت به خط تیره و فاصله)؛ پیشنهاد زنده برای Ctrl+K. |
| `CompareController.php` | `/compare` | مقایسه تا ۳ محصول، ردیف‌های متفاوت برجسته. |
| `FinderController.php` | `/finder`، `/finder/results` | راهنمای سه‌مرحله‌ای (نیاز ← پروتکل ← برند) و نتیجه با فیلتر کوچک. |
| `InquiryController.php` | `POST /inquiry` | ثبت **کلیک** ارسال استعلام در واتساپ (نه تحویل پیام): اقلام، تعداد، نام و پروژه اختیاری. محصول پیش‌نویس یا ناشناخته رد می‌شود. |
| `DeployController.php` | `/_deploy` | نصب بدون SSH: با کلید `DEPLOY_TOKEN` جدول‌ها را می‌سازد یا به‌روز می‌کند، کش‌ها را تازه می‌کند و بار اول داده اولیه را می‌ریزد. بدون کلید در `.env` اصلاً وجود ندارد (۴۰۴). |

## انجام‌شده
- همه صفحه‌های کاتالوگ موبایل و دسکتاپ با پوسته ClickUp.
- فیلتر هر دسته با منطق «یا» داخل هر گروه و «و» بین گروه‌ها، شمارش زنده نتیجه.
- ثبت کلیک استعلام با محدودیت تعداد درخواست (۲۰ در دقیقه).
- قلاب نصب برای هاست بدون SSH و برای GitHub Actions.

## باقی‌مانده
- `sitemap.xml` برای موتورهای جست‌وجو.
- صفحه «پروژه‌های اجراشده» وقتی عکس‌ها برسند (جدول `showcase_projects` آماده است).
- صفحه ۴۰۴ و ۵۰۰ با پوسته جدید (الان صفحه ساده Laravel است).
