# منطق اصلی (`app/Support`)

کلاس‌هایی که کار واقعی را انجام می‌دهند و کنترلرها فقط صدایشان می‌زنند. هیچ کتابخانه بیرونی اضافه‌ای ندارند تا روی هاست اشتراکی بی‌دردسر اجرا شوند.

## فایل‌ها

| فایل | کار |
|---|---|
| `Fa.php` | ابزار فارسی: رقم فارسی، یکسان‌سازی «ی/ك»، فشرده کردن کد مدل برای جست‌وجو (`ZVIZ-50A` = `zviz50a`)، تاریخ شمسی، «۳ ساعت پیش». |
| `Icons.php` | آیکون‌های تک‌مسیری SVG، تولیدشده از `project/Icon.dc.html`. |
| `Asset.php` | آدرس CSS و JS با نسخه بر اساس زمان تغییر فایل، تا مرورگر نسخه قدیمی را نگه ندارد. |
| `CatalogFilter.php` | فیلتر صفحه دسته: گروه‌های فیلتر هر دسته، شمارش هر گزینه، «یا» داخل گروه و «و» بین گروه‌ها، چیپ‌های فعال، پیشنهاد «بدون این فیلتر N نتیجه». |
| `CatalogNav.php` | داده منوی کناری کاتالوگ: دسته‌ها زیر گروه مادر با تعداد محصول منتشرشده، برندها. ۵ دقیقه کش، با ذخیره محصول پاک می‌شود. |
| `Search.php` | جست‌وجوی نام و کد مدل، برجسته کردن بخش منطبق کد. |
| `ProductAudit.php` | «تکمیل اطلاعات» هر محصول به درصد، فهرست کمبودها و **موانع انتشار** (نام، کد، برند، دسته، فیلدهای «لازم برای انتشار»). عکس، دیتاشیت و پروتکل فقط هشدارند. |
| `MediaStore.php` | ذخیره عکس و دیتاشیت در `public/media`؛ عکس‌ها به WebP با حداکثر ۱۶۰۰ پیکسل تبدیل می‌شوند. |
| `Activity.php` | ثبت هر کار در `activity_log` (چه کسی، چه چیزی، چه تغییری). |
| `AdminTree.php` | داده درخت کاتالوگ پنل: تعداد و تعداد ناقص هر دسته، پیش‌نویس‌ها، حذف‌شده‌ها. ۲ دقیقه کش. |
| `Xlsx.php` | خواندن و نوشتن فایل `.xlsx` بدون کتابخانه بیرونی، با سقف حجم و ردیف در برابر فایل مخرب. |
| `ProductSheet.php` | قلب به‌روزرسانی از فایل: ساخت خروجی اکسل، تحلیل فایل برگشتی (جدید، ویرایش، بدون تغییر، غایب، خطاها با شماره ردیف)، اعمال در یک تراکنش با پشتیبان JSON، بازگردانی. |
| `FritzPackage.php` | قالب `.fritz`: رمزنگاری AES-256-GCM با کلید PBKDF2؛ تشخیص «رمز اشتباه» از «فایل دستکاری‌شده»؛ نگهداری رمز بسته در تنظیمات و اثر انگشت آن. ابزار مرورگری `resources/views/admin/update/packer.blade.php` باید با این فایل سازگار بماند. |

## انجام‌شده
- همه موارد بالا با آزمون خودکار.
- قانون‌های فایل به‌روزرسانی در `docs/PLAN.md` («قانون فایل به‌روزرسانی») نوشته شده‌اند.

## باقی‌مانده
- عکس و دیتاشیت از طریق فایل اکسل (الان فقط از فرم محصول).
- در `bulk restore` کش درخت پنل تا ۲ دقیقه دیر به‌روز می‌شود (بازگردانی گروهی رویداد ذخیره نمی‌زند).
