# صفحه‌ها (`resources/views`)

همه HTML سایت با Blade، سمت سرور ساخته می‌شود (برای سئو و سرعت در موبایل). تعامل‌ها با Alpine.js داخل همان صفحه است.

| پوشه | کار | راهنما |
|---|---|---|
| `catalog/` | صفحه‌های عمومی کاتالوگ | [README](catalog/README.md) |
| `admin/` | صفحه‌های پنل مدیریت | [README](admin/README.md) |
| `components/` | تکه‌های تکرارشونده و دو پوسته اصلی (کاتالوگ و پنل) | [README](components/README.md) |
| `partials/` | سه تکه مشترک کاتالوگ (پایین) | — |

## `partials/`

| فایل | کار |
|---|---|
| `art-sprite.blade.php` | نقاشی‌های جای عکس محصول (تاچ پنل، کلید، رله، سنسور…)، تولیدشده از `project/ProductArt.dc.html`. تا رسیدن عکس واقعی استفاده می‌شوند. |
| `inquiry-drawer.blade.php` | کشوی «لیست استعلام»: اقلام و تعداد، نام و پروژه اختیاری، پیش‌نمایش پیام، دکمه «ارسال استعلام در واتساپ». روی دسکتاپ پنل کناری، روی موبایل شیت پایین. |
| `toast.blade.php` | پیام کوتاه پایین صفحه («به لیست استعلام اضافه شد» با لینک «مشاهده لیست»). |

## قانون‌های ثابت در همه صفحه‌ها
- هیچ قیمت، موجودی یا سبد خریدی در صفحه عمومی نیست (آزمون `test_public_pages_never_show_price_or_stock`).
- کدهای مدل و نام برندها لاتین و جدا از متن فارسی (`.code`، `.lat`، `<bdi>`).
- رنگ لیمویی کامل فقط برای دکمه اصلی هر صفحه، شمارنده‌ها و حالت انتخاب‌شده.
