# اجزا و پوسته‌ها (`resources/views/components`)

تکه‌هایی که در چند صفحه تکرار می‌شوند، با `<x-نام>` صدا زده می‌شوند.

## فایل‌ها

| فایل | استفاده | کار |
|---|---|---|
| `layouts/site.blade.php` | `<x-layouts.site>` | پوسته کاتالوگ: منوی کناری با درخت دسته‌ها و برندها، نوار پایین موبایل (خانه، دسته‌ها، جست‌وجو، مقایسه، استعلام)، جست‌وجوی Ctrl+K، کشوی استعلام، سئو و `noindex` تا وقتی ایندکس روشن نشده. |
| `layouts/admin.blade.php` | `<x-layouts.admin>` | پوسته پنل: نوار آیکون خاکستری، درخت کاتالوگ با تعداد و میزان تکمیل هر دسته، نوار بالا (مسیر، Ctrl+K، «+ جدید»، حساب)، پنجره تأیید کارهای خطرناک. بخش‌های قفل‌دار برای «ویرایشگر محتوا» پنهان‌اند. |
| `hdr.blade.php` | `<x-hdr>` | نوار بالای کاتالوگ: منو یا بازگشت، مسیر صفحه، جست‌وجو، تم، «لیست استعلام» با شمارنده. |
| `pcard.blade.php` | `<x-pcard>` | کارت محصول: تصویر، برند، نام، کد، پروتکل، «مقایسه»، «افزودن به استعلام». بدون قیمت. |
| `pimg.blade.php` | `<x-pimg>` | عکس اصلی محصول، یا نقاشی جای عکس دسته‌اش. |
| `art.blade.php` | `<x-art>` | یک نقاشی از `partials/art-sprite`. |
| `icon.blade.php` | `<x-icon>` | یک آیکون از `app/Support/Icons.php`. |
| `status.blade.php` | `<x-status>` | چیپ وضعیت محصول در پنل که خودش منو است؛ برگرداندن به پیش‌نویس تأیید می‌خواهد. |
| `foot.blade.php` | `<x-foot>` | پانویس کاتالوگ با دکمه واتساپ و لینک‌ها (در صفحه «درباره و تماس»). |

## انجام‌شده
- دو پوسته کامل با تم روشن و تیره و نسخه موبایل.

## باقی‌مانده
- جایگزینی لوگوی PNG با SVG وقتی کارفرما بفرستد.
