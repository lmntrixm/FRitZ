# صفحه‌های پنل مدیریت (`resources/views/admin`)

همه داخل پوسته `components/layouts/admin.blade.php` (نوار آیکون، درخت کاتالوگ، Ctrl+K، «+ جدید»). طراحی اولیه در `project/A-*` بود؛ به درخواست کارفرما به سبک ClickUp بازطراحی شد.

## فایل‌ها

| فایل | آدرس | کار |
|---|---|---|
| `_auth.blade.php` | — | قالب مشترک صفحه ورود و راه‌اندازی. |
| `login.blade.php` | `/admin/login` | ورود، شمارش تلاش‌های اشتباه و قفل ۱۵ دقیقه‌ای. |
| `setup.blade.php` | `/admin/setup` | ساخت اولین «مدیر کل» با کلید راه‌اندازی. |
| `overview.blade.php` | `/admin` | نمای کلی: آمار، نمودار استعلام ۱۲ هفته، سهم برند و پروتکل، «نیاز به توجه»، فعالیت اخیر. |
| `settings.blade.php` | `/admin/settings` | واتساپ و قالب پیام با پیش‌نمایش، تماس، سئو، **کلید رمزنگاری** فایل `.fritz`. |
| `soon.blade.php` | بخش‌های ساخته‌نشده | صفحه صادقانه «مرحله بعد». |
| `products/index.blade.php` | `/admin/products` | سه نما: لیست گروه‌بندی‌شده (وضعیت، دسته یا برند)، جدول صفحه‌بندی‌شده، بُرد با کشیدن کارت؛ فیلتر، «فقط ناقص‌ها»، عملیات گروهی، حذف‌شده‌ها. |
| `products/peek.blade.php` | پنل کناری | خلاصه محصول، کمبودها و موانع انتشار، مشخصات، تغییر وضعیت در جا. |
| `products/form.blade.php` | ساخت و ویرایش | فرم شش‌بخشی: پایه، مشخصات فنی پویای دسته، توضیحات، رسانه، ارتباطات، اطلاعات داخلی (قیمت «فقط داخلی، عمومی نمی‌شود»)؛ پیش‌نمایش زنده کارت عمومی. |
| `update/index.blade.php` | `/admin/update` | بارگذاری `.fritz` یا اکسل، خروجی اکسل و قالب خالی، ابزار ساخت بسته، تاریخچه. |
| `update/show.blade.php` | `/admin/update/{n}` | پنج مرحله: اعتبارسنجی با شماره ردیف، پیش‌نمایش تغییرها، گزینه‌ها، تأیید و اعمال؛ نتیجه و بازگردانی. |
| `update/packer.blade.php` | `/admin/update/packer` | ابزار آفلاین تک‌فایلی برای ساخت `.fritz` در مرورگر؛ اثر انگشت رمز را با سایت مقایسه می‌کند. |

## انجام‌شده
- ورود، راه‌اندازی، نمای کلی، تنظیمات، محصولات، به‌روزرسانی؛ همه با پوسته ClickUp، تم تیره و موبایل.
- هر کار خطرناک با پنجره تأیید و توضیح اثر.

## باقی‌مانده
- صفحه‌های استعلام‌ها، دسته‌ها و فیلترها، برندها و پروتکل‌ها، رسانه، کاربران، گزارش فعالیت (طرح‌شان در `project/A-Inquiries`، `A-Categories`، `A-Brands`، `A-Media`، `A-Users`، `A-Activity` آماده است).
- نسخه تبلت پنل (`project/A-Tablet`).
