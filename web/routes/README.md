# آدرس‌ها (`routes`)

| فایل | کار |
|---|---|
| `web.php` | همه آدرس‌های سایت. **بخش عمومی:** `/`، `/c/{دسته}`، `/p/{محصول}`، `/search`، `/search/suggest`، `/compare`، `/finder`، `/about` و `POST /inquiry` (ثبت کلیک استعلام). **پنل `/admin`:** ورود و راه‌اندازی بدون نیاز به ورود قبلی؛ نمای کلی و محصولات برای هر کاربر واردشده؛ تنظیمات و به‌روزرسانی فقط برای مدیر کل؛ بقیه بخش‌ها صفحه «مرحله بعد». محدودیت درخواست روی ورود، راه‌اندازی، پیشنهاد جست‌وجو و ثبت استعلام. |
| `console.php` | دستور `php artisan fritz:user` (ساخت یا به‌روزرسانی کاربر پنل از خط فرمان) و زمان‌بندی روزانه `model:prune` (پاک کردن قطعی محصولات حذف‌شده بیش از ۳۰ روز). |

آدرس `/_deploy` در `bootstrap/app.php` ثبت شده، بیرون از گروه وب، چون پیش از اولین نصب هنوز جدول نشست وجود ندارد.

## انجام‌شده
- همه آدرس‌های کاتالوگ، پنل، محصولات و به‌روزرسانی.

## باقی‌مانده
- آدرس‌های بخش‌های بعدی پنل (استعلام‌ها، دسته‌ها، برندها، رسانه، کاربران، گزارش فعالیت).
- `sitemap.xml`.
- روی هاست، Cron Job زمان‌بندی باید یک بار در DirectAdmin ساخته شود (`docs/DEPLOY.md`، بخش Cron).
